MODEL PROPOSAL — qualitative interpretation, not an established result
hypothesis: Exploratory hypothesis for later independent evaluation on this frozen convenience sample: dividing the trailing close return over the baseline lookback by the trailing realized daily-return standard deviation scaled by the square root of that lookback yields a short-horizon momentum score expressed relative to each symbol's own recent return dispersion. Motivation: cited profiles show material cross-symbol heterogeneity in one-observation return dispersion, so raw trailing-return magnitudes conflate symbol-specific volatility scale with signal information; a per-symbol dispersion scaling is intended to make score magnitudes interpretable on a common dimensionless scale across the fixed universe. This is a research question, not a claim: usefulness, sign persistence, tradability and any investment benefit are unproven; the normalized score is not an annual Sharpe ratio and does not remove systematic risk. Signals use only observations at or before the signal close, windows use past observed rows only with no filling, and execution can occur no earlier than the next observed close; the final signal row has no execution observation, and available next observed closes are coverage facts only, not tradability. Evidence needed next: forward performance labels in a separate future evaluation, outside this descriptive stage.

rationale: Retained the baseline lookback and direction; changed only normalization, adding realized-volatility scaling with the volatility window at its minimum permitted value, matching the baseline lookback. The added parameter is justified by cited evidence: profiles show material cross-symbol heterogeneity in one-observation return dispersion, and unnormalized scores inherit differing sample score scales, so cross-symbol magnitudes conflate symbol-specific volatility scale with signal information. Its score-scale consequence is that dispersions and magnitudes move onto a common per-symbol dispersion scale of comparable order across the three symbols rather than raw-return scales; this is a descriptive rescaling, not proof of improved information content or a better specification. No applicability exclusion was added: close-only jumps cannot identify corporate actions and no cited finding licenses a return bound, so that bound stays null. Retaining the baseline remained coherent and was set aside only as the weaker fit to the cross-symbol research question, not as invalid.
